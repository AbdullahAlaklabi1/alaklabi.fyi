# Alaklabi Terminal Portfolio

Static academic portfolio inspired by a terminal interface.

## Preview locally

```bash
python -m http.server 8000
```
Then open http://localhost:8000

## Deploy

Upload the folder to GitHub Pages, Cloudflare Pages, Netlify, or Vercel. Set your custom domain (for example `alaklabi.fyi`) in the hosting provider, then point the domain DNS records to that host.

## Terminal commands
`help`, `whoami`, `ls`, `about`, `research`, `publications`, `dissertation`, `cv`, `contact`, `clear`.
